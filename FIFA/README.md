# FIFA: reglas de asociación con PrefixSpan

1. Descarga `FIFA.txt` de https://www.philippe-fournier-viger.com/spmf/publicdatasets/FIFA.txt y colócalo en `FIFA/data/`.
2. Instala las dependencias: `pip install -r requirements.txt` (desde la raíz del repositorio).
3. Ejecuta el notebook `prefixspan_reglas_asociacion.ipynb`, modificando, si se desea, el soporte mínimo en la primer celda de la sección 3: Transformación.
